# Docs UI

Documentation UI built with Vite, React, TypeScript, shadcn-ui, and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

## Scripts

```sh
npm run dev
npm run build
npm run build:dev
npm run preview
npm run lint
npm run test
npm run test:watch
```

## Deployment

Production is the static Worker `beyou-docs` on Cloudflare, at docs.beyouweb.com (`wrangler.jsonc`). The `deploy` job in `.github/workflows/ci.yml` runs on every push to `main` and on the `docs-content-updated` event that beyou-arch-design sends after a content import. It prerenders every page against the public docs API, then runs `wrangler deploy`.

The build writes three files Cloudflare reads at deploy time and never serves: `_headers` (from `public/`), `.assetsignore` (from `public/`, keeps source maps out of the upload) and `_redirects` (generated by `scripts/prerender.mts`, sends `/blog/x` to `/en/blog/x`). The pages call the API at `VITE_BACKEND_URL`, so the backend's `CORS_ALLOWED_PATTERN` has to list the docs origin.

The Dockerfile and `nginx.conf` still build a self-contained nginx image for running the site locally.
